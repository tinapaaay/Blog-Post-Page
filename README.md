# Blog Post Page

A semantic and responsive blog post page built with HTML and CSS.

This project presents one long-form blog post about learning web development through small projects. It uses meaningful HTML elements for article content, then adds a clean reading-focused design with CSS.

## Features

- Semantic page structure using `header`, `main`, `article`, and `footer`
- Clear heading structure with `h1`, `h2`, and `h3`
- Navigation links with descriptive text
- Responsive article layout
- Featured image inside a `figure` with alt text and a caption
- Semantic lists, blockquotes, inline code, and code blocks
- Meaningful emphasis using `strong` and `em`
- Image cropping with `object-fit: cover`

## Built With

- HTML5
- CSS3

## What I Practiced

- Semantic markup for long-form content
- Accessible image descriptions
- Heading hierarchy
- Descriptive link text
- Styling readable article content
- Responsive navigation
- CSS typography and spacing
